Nothing is being autoscaled yet. Two objects are needed:

1. A ForecastBackend. Start with the in-process baseline -- it needs no model
   server, and it is the number a foundation model has to beat before it earns
   a node:

     kubectl apply -f - <<'YAML'
     apiVersion: scaling.presage.sh/v1alpha1
     kind: ForecastBackend
     metadata:
       name: default
     spec:
       type: SeasonalNaive
       seasonalNaive:
         season: 168h
         cycles: 3
     YAML

2. A PredictiveScaler for a workload. See:
     https://github.com/breezycourses/presage/tree/main/examples

Every PredictiveScaler defaults to mode: Shadow, which publishes a
recommendation and changes nothing. Compare it against reality first:

  kubectl get predictivescalers -A
  # presage_recommended_replicas  vs  presage_current_replicas
