# Code of Conduct

This project follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

In short: be respectful, assume good faith, and remember that most people
reading a thread are trying to get something working rather than to be right.

Report unacceptable behaviour to me@growly.gg. Reports are handled privately.
